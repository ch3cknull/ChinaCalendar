如何订阅

在日历应用中选择“添加订阅日历”，粘贴上方 HTTPS 链接。也可下载 ICS 文件后导入。

放假日期和补班安排以各年度录入数据及其来源为准，具体年份和日期请查看订阅日历中的日程说明。订阅后可由日历应用定期获取更新；单次导入不会自动更新。
